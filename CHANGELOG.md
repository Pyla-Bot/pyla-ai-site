# Changelog

## 1.0.0 - Initial static site

- Added responsive dark themed Pyla AI website with Home, Features, Install, Docs, Download, and Community pages.
- Added copied local PNG assets, generated social image placeholder, favicon placeholder, SEO metadata, robots.txt, CNAME placeholder, and GitHub Pages support files.

- Added a `/docs` mirror so GitHub Pages works when configured for `main` branch and `/docs` folder.
- Added a GitHub Actions Pages workflow for reliable static deployment from the repository root.
- Cleared the placeholder `CNAME` value because GitHub Pages treats that file as a real custom domain.
