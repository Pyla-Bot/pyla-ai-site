Install

Set up Pyla AI correctly the first time

Use Windows 10/11, Python 3.11.9, an ADB-capable emulator, and the display settings recommended by the project docs.

1

Install an emulator

LDPlayer is recommended. BlueStacks and other emulators can work if ADB is enabled and screen settings match the expected layout.

2

Enable ADB

Turn on Android Debug Bridge access in the emulator settings, restart the emulator, and confirm the device is visible before launching Pyla AI.

3

Install Python 3.11.9

Use Python 3.11.9 on Windows and follow the repository instructions for dependencies or release builds.

4

Set resolution, DPI, and display zoom

Warning: Having incorrect display settings can cause the Start button to be hidden in the Pyla AI window!

For BlueStacks, check display resolution and DPI under emulator settings. Restart after changing DPI so the UI and ADB capture dimensions update cleanly.

5

Watch the setup tutorial

Use the YouTube walkthrough if you want to verify emulator, ADB, and display settings visually.

Open the YouTube tutorial

6

Launch and verify

Start the emulator, open Brawl Stars, run Pyla AI, and confirm detection status before long sessions.
