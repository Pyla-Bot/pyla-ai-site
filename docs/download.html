Getting Started

Install Python 3.11.9, choose an ADB-capable emulator, and download the latest public release or clone the repository.

Release checklist

  • Confirm Windows 10/11 support
  • Install Python 3.11.9 if running from source
  • Use matching model files for your release
  • Read install notes before changing emulator DPI
  • Check Discord for early builds and the latest changelog.
