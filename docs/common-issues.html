Common Issues

Use this guide when Pyla AI starts incorrectly, cannot connect to the emulator, or behaves differently than expected in matches.

ONNX Runtime or LoadLibraryExW error

Symptoms: Pyla AI may show an error mentioning LoadLibraryExW, onnxruntime_pybind11_state.pyd, or ImportError: The specified module could not be found.

Fixes: Use Python 3.11.x, with Python 3.11.9 recommended. Update your GPU drivers, then install the latest supported Microsoft Visual C++ Redistributable.

Can't connect to server

Cause: Some internet providers block the hosting provider used by the app or its downloads. This is reported most often by users in Russia.

Fix: Try a VPN and reopen Pyla AI after the connection changes. Common free or paid options include ProtonVPN, Windscribe, Cloudflare WARP, NordVPN, ExpressVPN, and Mullvad.

ADB or Scrcpy connection errors

Symptoms: The app may stay on "Connecting to ADB...", fail with "Failed to initialize Scrcpy", or show tracebacks that reference ADB.

Fixes: Enable ADB in the emulator settings, restart the emulator, and reboot the PC if the ADB device list stays stale. Check whether antivirus software is blocking emulator or Scrcpy processes. Disconnect any phone connected over USB because USB debugging can take over the ADB connection. If the issue continues, test another emulator such as LDPlayer, BlueStacks, or Mumu.

Watch the ADB troubleshooting tutorial

Bot not using super, gadget, or hypercharge

Set the emulator resolution to 1920x1080 and DPI to 280. Reset the Brawl Stars control positions so the buttons are back in expected locations. If the super still is not detected reliably, lower the Super Pixels Threshold in Additional Settings and test again.

Hypercharge not activating

Edit cfg/buttons_config.toml, change the hypercharge button coordinates, then restart Pyla.

hypercharge = [1400, 900]

Change it to:

hypercharge = [1400, 990]

Bot walking into storm or delayed movement

Cause: The emulator may be delaying the image feed that Pyla AI uses for decisions. LDPlayer can show this behavior on some systems.

Fix: Switch emulators and retest the same settings. Mumu is recommended when movement looks delayed or the bot reacts to old frames.
