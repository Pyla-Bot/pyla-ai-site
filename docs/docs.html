Pyla AI docs

Getting Started

Install Python 3.11.9, choose an ADB-capable emulator, and download the latest public release or clone the repository.

Running

Start the emulator first, verify Brawl Stars is open, then launch Pyla AI and check that detection and ADB state are ready before pressing Start.

Troubleshooting

Most launch issues come from incorrect display scale, emulator resolution, missing ADB access, or unsupported Python versions.

Warning: Having incorrect display settings can cause the Start button to be hidden in the Pyla AI window!

Models

Detection models are used to identify enemies, walls, and relevant match state. Keep model files paired with the release they were built for.

GUI

The GUI exposes start controls, detection state, configuration, and run feedback. Use default settings first, then tune one value at a time.

Code Overview

The repository is organized around emulator input, frame capture, model inference, GUI state, and logging. Review the GitHub repo before modifying behavior.
